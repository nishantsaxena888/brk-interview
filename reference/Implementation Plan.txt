Implement Phase 01: Core AWS (Modules 01 - 07)
The objective is to expand the existing interactive Lambda Masterclass learning platform to include the first 7 foundational AWS chapters from Phase 01. We will use the same data-driven architecture (HTML shell + JS data files mapping to interactive engines) that we used for modules 08 through 14.

Update Course Registry
Update js/data/courses.js to insert Modules 01 through 07 at the beginning of the modules array. This includes adding module metadata (ID, title, description, color, difficulty, icon, duration, and lessons) and related achievements.
