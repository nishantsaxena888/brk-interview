MasterclassUI Component Library

Standardized, data-driven interactive UI components designed for cloud architecture, programming sandboxes, technical tutorials, and interactive quizzes. Drop them into any framework or plain HTML.

1. Interactive Terminal Component

Simulated CLI with pattern-matching commands, prompt customization, and live command logging.
<ui-terminal> 
<!-- HTML Web Component Usage -->
<ui-terminal title="AWS CLI Sandbox" prompt="aws-user$ " mode="simulated">
  <script type="application/json">
    {
      "aws sts get-caller-identity": "{\n  \"UserId\": \"AROAEXAMPLEID\",\n  \"Account\": \"123456789012\",\n  \"Arn\": \"arn:aws:iam::123456789012:user/developer\"\n}",
      "help": "Available commands: aws sts get-caller-identity, help, clear"
    }
  </script>
</ui-terminal>

<!-- Or JavaScript API -->
MasterclassUI.Terminal('#my-container', {
  title: 'AWS CLI Sandbox',
  prompt: 'aws-user$ ',
  commands: { 'help': 'Available commands...' }
});

2. Interactive Code Editor Component

Code editor with syntax tabs, line numbering, reset, and run-code sandbox capability.
<ui-code-editor> 
<!-- HTML Web Component Usage -->
<ui-code-editor title="Lambda Handler (Python)" language="python">
  <script type="text/plain">
import json

def lambda_handler(event, context):
    return {
        "statusCode": 200,
        "body": json.dumps({"message": "Hello from MasterclassUI!"})
    }
  </script>
</ui-code-editor>

3. Interactive Quiz Component

Instant evaluation, explanations, score tracking, and automated PostgreSQL syncing.
<ui-quiz> 
MasterclassUI.Quiz('#my-quiz-container', {
  title: 'Cloud Knowledge Check',
  questions: [
    {
      id: 'q1',
      question: 'Which service enables fully-managed serverless foundation models in AWS?',
      options: ['Amazon Bedrock', 'Amazon EC2', 'Amazon S3', 'AWS Snowball'],
      correctIndex: 0,
      explanation: 'Amazon Bedrock provides unified API access to leading foundation models serverlessly.'
    }
  ],
  onQuestionAnswer: (qId, selectedIndex, isCorrect) => console.log(qId, isCorrect)
});

4. CLI Command Block Component

1-Click copy button, syntax styling, and descriptive header.
<ui-command> 
<ui-command 
  title="Verify AWS Identity" 
  command="aws sts get-caller-identity --output table" 
  description="Validates active AWS credentials and account permissions.">
</ui-command>

5. Architecture Diagram Component

Interactive nodes and dataflow diagrams with hover state insights.
MasterclassUI.Diagram 
MasterclassUI.Diagram('#diagram-container', {
  title: 'Serverless Event Pipeline',
  nodes: [
    { id: 'client', label: 'Client App', icon: '📱', desc: 'Mobile/Web user sending requests' },
    { id: 'apigw', label: 'API Gateway', icon: '🚪', desc: 'REST API routing & throttling' },
    { id: 'lambda', label: 'AWS Lambda', icon: '⚡', desc: 'Serverless backend computation' },
    { id: 'db', label: 'DynamoDB', icon: '🗄️', desc: 'Sub-millisecond NoSQL persistence' }
  ],
  connections: [
    { from: 'client', to: 'apigw', label: 'HTTPS' },
    { from: 'apigw', to: 'lambda', label: 'Payload' },
    { from: 'lambda', to: 'db', label: 'PutItem' }
  ]
});
