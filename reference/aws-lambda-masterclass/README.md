# AWS Masterclass Interactive Web Platform

Interactive learning platform with hands-on labs, architectural diagrams, quizzes, simulated consoles, and coding challenges across 37 AWS modules.

## How to Run Locally

### 1. Using Python (Recommended)
```bash
# Default port (8080)
python -m http.server 8080

# Or any custom port (e.g., 3000, 5000, 8889)
python -m http.server 5000
```

### 2. Using Node.js (npx)
```bash
npx serve -l 8080
```

### 3. Using Batch Script (Windows)
Run `..\start_server.bat` or `..\start_server.bat 8080` from `Uday_AWS_Services_notes`.

## URLs
- Landing Page: `http://localhost:8080/index.html`
- Modules: `http://localhost:8080/modules/module-01.html` (through `module-37.html`)
